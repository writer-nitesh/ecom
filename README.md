# ECOM Store

[Live Here](https://ecom-0x99f.vercel.app/)

ECOM  is an e-commerce shopping website built with nextjs

## Tech Stack

- NextJS
- TailwindCSS
- Typescript
- Fake Store API
- Zustand (State Management)
- React Icons
